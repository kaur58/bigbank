Create a NodeJS console program (using the api documented https://dragonsofmugloar.com/doc/) which:

* Starts a new game
* Fetches a list of ads
* Picks the best ads to solve and solves them
* Optionally buys items to improve its chances.
* Repeats from step two until lives run out.

MUST HAVE:
* Good code quality and organization
* Use of best practices and design patterns
* unit tests
* proper error handling
